# البيئة التجريبية المعزولة (Demo Sandbox)

للمراجعين (Google Play) والمختبرين: دخول بلا حساب وبلا لمس أي بيانات حقيقية. نموذجها نموذج مِراس.

## كيف تعمل
1. زر «تجربة العرض بلا حساب» (نافذة الدخول، الصفحة الرئيسية، والشريط العلوي) يستدعي `POST /api/v1/demo/enter`.
2. الخادم يُصدر معرّفًا موقَّعًا `demo_` + 64 ست عشري (nonce + HMAC مشتق من `AUTH_SESSION_SECRET`؛ المعرّف المزوَّر يُردّ 403 قبل حجز أي شيء)، ويفتح قاعدة **SQLite في الذاكرة** خاصة بالزائر (لا اتصال بـ `DATABASE_URL` ولا بملف).
3. المتصفح يحفظ المعرّف في `sessionStorage` (لكل لسان صندوقه) ويرسله في ترويسة `x-majal-demo` مع كل نداء `/api/` (Firebase Hosting يحذف كل الكوكيز إلا `__session`).
4. واجهة العرض نفسها (بيانات مصطنعة محلية في المتصفح) تبقى كما كانت؛ الجديد أن كل طلب يخرج منها إلى الخادم مقيَّد بالصندوق.

## طبقات العزل (على الخادم)
- `demoGuard` (قبل أي موجّه): طلب بمعرّف صالح لا يطابق **قائمة السماح** (قراءة فقط: health/version/`auth/me`/`public/*`/`/api/v1/demo/*`) يُردّ `403 DEMO_SANDBOX_BLOCKED`. يشمل الدفع، PACI، الإشعارات، الذكاء الاصطناعي، الويب هوك، الإدارة، وتسجيل الدخول/التسجيل الحقيقي. لا يعتمد على AsyncLocalStorage.
- `createDemoAwareDb`: داخل سياق الصندوق كل `prepare/exec/transaction` يذهب لقاعدة الصندوق، لا للحقيقية.
- ترويسة `Cookie` تُحذف من طلب الصندوق: لا جلسة حقيقية تصل ولا يُمسح لها كوكي.
- `demoContext` بعد `express.json` عمدًا (قراءة الجسم قد تُضيّع السياق).
- لا تغيير على مصادقة الحسابات الحقيقية (جلسات HttpOnly، CSRF، MFA، RBAC كما هي).

## الحدود
- سقف 40 صندوقًا متزامنًا (`DEMO_MAX_SANDBOXES`)، مهلة 30 دقيقة من آخر نشاط، تنظيف كل دقيقة.
- `POST /api/v1/demo/enter|reset`: 20 طلبًا / 15 دقيقة / IP.
- الصندوق في ذاكرة العملية: إعادة تشغيل Cloud Run تمسحه (يُعاد بناؤه فارغًا عند أول طلب، دون سقوط على الحقيقية).

## التشغيل والإيقاف
- مفعّل افتراضيًا. **مفتاح الإيقاف:** `MAJAL_DEMO_ENABLED=false` ← `enter` و أي طلب يحمل معرّف صندوق يردّان 404.
- بناء العميل بلا عرض: `VITE_DISABLE_DEMO_MODE=true` (كما كان).

## الفحص
- `npm run verify:demo` — فحص ثابت لسلسلة الربط (الأزرار، الناقل، ترتيب الوسطاء).
- `node --import tsx --test server/demo-sandbox.test.ts` — اختبارات العزل: لا قراءة ولا كتابة للقاعدة الحقيقية، سقوط الكوكي، قائمة السماح، السقف، المهلة، مفتاح الإيقاف.
